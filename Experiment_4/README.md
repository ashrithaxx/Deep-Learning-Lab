# Comparative Study of Deep Convolutional Neural Network Architectures Using Transfer Learning

A TensorFlow/Keras implementation of transfer learning using MobileNetV2 for multi-class image classification on the CIFAR-10 dataset.

## Features

- CIFAR-10 data preprocessing
- MobileNetV2 pretrained model implementation
- Transfer learning with a frozen base
- Fine-tuning of the final layers
- Training and validation accuracy/loss visualization
- Classification report
- Confusion matrix
- Misclassified image visualization
- Model evaluation using Accuracy, Precision, Recall, and F1-score

## Tech Stack

- Python
- TensorFlow / Keras
- Scikit-learn
- NumPy
- Matplotlib

## Results

- Test Accuracy: 88.30%
- Precision (macro): 88.20%
- Recall (macro): 88.30%
- F1-score (macro): 88.20%
- Total Parameters: 2,588,490

## Contents

- `Comparative Study of Deep Convolutional Neural Network Architectures Using Transfer Learning.ipynb` – Jupyter notebook with full implementation
- `Comparative Study of Deep Convolutional Neural Network Architectures Using Transfer Learning.pdf` – Lab manual with theory, implementation, results, and discussion
- `images/` – Training and evaluation visualizations
